# 🎓 MC_learning_VLU

> Bài tập thực hành môn **Machine Learning** — Đại học Văn Lang (VLU)

## 📋 Mô tả

Repository này chứa các bài tập thực hành Machine Learning, được tổ chức theo từng chủ đề/thuật toán. Mỗi folder là một buổi học với nhiều bài tập từ cơ bản đến nâng cao, sử dụng Python.

## 📁 Cấu trúc thư mục

| STT | Chủ đề | Nội dung |
|-----|--------|----------|
| 01 | **Linear Regression** | Hồi quy tuyến tính — phân tích dữ liệu giá nhà, gradient descent, learning rate |
| 02 | **Logistic Regression** | Hồi quy logistic — phân loại nhị phân, hàm sigmoid, dự đoán qua môn |
| 03 | **Naive Bayes** | Phân loại Bayes đơn giản — phân loại văn bản, dự đoán spam, xemail
